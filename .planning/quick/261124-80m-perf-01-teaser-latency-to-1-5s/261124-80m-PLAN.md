Teaser critical path today (src/app/api/chat/stream/route.ts):
1. `request.json()` + `validateChatBody`
2. `cataloguePromise = getCatalogue()` started, then `retrieveContext({... onChunks: emitTeasers})`
3. In `retrieveContext` (src/lib/supabase.ts:517): RAG cache check -> `detectQueryIntent` -> `hybridSearchV2` = `generateEmbedding(query)` (OpenRouter `openai/text-embedding-3-small`, in-memory cache + in-flight dedupe) THEN `supabase.rpc('hybrid_search_v2', {match_count: 60, ...})`. In parallel it fires `searchVisualAssets` (shares the embedding, plus `visualAssetsIndexed` count), `getTaxonomy()`, `getAllDocumentMetrics()`. Rerank is OFF (`concierge-config.ts` rerank.enabled=false), so `poolP` resolves immediately.
4. After the RPC: best-per-document selection, then `onChunks(finalChunks)` -> `emitTeasers` waits on `cataloguePromise` -> `decideInstantTeasers` -> `send({type:'teasers'|'suppressed'})`.
5. Only after that does `orchestrateStream` start.

`getCatalogue()` (src/lib/catalogue.ts, 1 h in-memory memo) on a cold instance runs 4 concurrent reads, one of which pages through EVERY embedded content_chunks row (`document_id, chunk_index, content`, 1000 rows/page, sequential pages) just to extract the "Solution included ..." deliverables line. Teasers wait on it. Strong cold-path suspect, but MEASURE it.

Eval 2026-11-24T10-42-25 (base_url localhost:3000) per-query t_teasers/t_suppressed in run order: the first ~10 queries are 2.7-7.9 s (server warm-up), steady state afterwards is 1.8-2.4 s for both teasers and suppressed events. So there are two problems to separate: cold/warm-up cost and a ~2 s steady-state floor.
Phase 5 05-TIMING measured retrieval 3.0-4.9 s in-process (includes the non-critical side fetches).

Gates already in the codebase: `debugEnabled(body)` = `body.debug === true && process.env.EVAL_DEBUG === 'true'` (src/lib/chat-request.ts:41). Note `debug` also sets skipCache, which we do NOT want for timing; hence a separate `teasersOnly` flag with the same env gate.
`.env` has OPENAI_API_KEY and EVAL_DEBUG set (values not read). `usingOpenRouter()` = OPENROUTER_API_KEY present, so embeddings go through OpenRouter today.
Test runner: `npm run eval:test` (= `tsx --test eval/*.test.ts`). Eval scripts `import './lib'` to load .env/.env.local.

<objective>
N runs with mean and spread (EVAL-05), run-level capture of route/model IDs (EVAL-07), a baseline re-grade command,
and a cost/Supabase preflight.

Purpose: one run's numbers move by noise; later phases need mean and spread to tell a real change from noise.
Phase 1 metric definitions change, so the frozen baseline responses must be re-graded under the new harness for a
like-for-like comparison (judge calls only, no generation). The OpenRouter key has about $45 left and one run costs
about $3.50, so every paid command checks remaining credit first. Supabase free tier pauses after inactivity;
restoring it is a human action, so the eval must stop with a clear message rather than record 50 errors.

Defaults chosen (Claude's discretion, per the user's "sensible defaults"): N defaults to 1 (`EVAL_RUNS` env or
`--runs`); spread = sample SD (n−1) plus min–max; SD shown as "–" when N = 1.

Output: preflight.ts, regrade.ts, batch.ts, aggregate.ts, run.ts refactor, npm scripts.
</objective>

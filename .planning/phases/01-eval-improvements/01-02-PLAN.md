       export interface Quantity { value: number; unit: QuantityUnit }

       Rules for extractQuantities:
       - Lowercase. Remove thousands separators: replace /(\d),(?=\d{3}(?!\d))/g with '$1' repeatedly until stable ("8,000,000" -> "8000000").
       - Number token: digits `\d+(?:\.\d+)?`, or a whole word from: zero one two three four five six seven eight nine ten eleven twelve thirteen fourteen fifteen sixteen seventeen eighteen nineteen twenty thirty forty fifty sixty seventy eighty ninety (single words only; matched with \b boundaries).
       - Optional scale right after the number (optional whitespace): `thousand|k` = 1e3, `million|mn|mm|m` = 1e6, `billion|bn|b` = 1e9, `trillion|tn|t` = 1e12. Short forms only count when NOT followed by a letter or digit (regex lookahead `(?![a-z0-9])`), so "8 more", "5 min" and "20 b2b" are unscaled. Try the long words before the short forms in the alternation.
       - Unit after the (scaled) number, optional whitespace and an optional '+': `%`, `percent`, `per cent`, `pct` -> 'percent'; `x` (not followed by a letter or digit), `times`, `-fold`, `fold` -> 'multiple'; otherwise 'plain'.
       - Ignore currency symbols ($ € £) and modifiers (over, more than, nearly, about, approximately, ~, +, up to, almost): they are simply not part of the token.
       sameQuantity: units equal AND (both values 0, or |a-b| <= 0.005 * max(|a|,|b|)).
       metricValueInContext: q = extractQuantities(value); if q.length === 0 return normalised-substring check (lowercase, collapse whitespace, trim) exactly like lib.ts `normalize`; else return every q item has a sameQuantity match in extractQuantities(contextText).

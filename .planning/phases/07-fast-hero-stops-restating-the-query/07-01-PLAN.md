    Create src/lib/hero-restatement.ts (pure; the only env read is in heroRestatementGuardEnabled):
    ```ts
    export const HERO_RESTATEMENT_VERSION = 1;
    export const HERO_RESTATEMENT_CONFIG = { verbatimRun: 6 } as const;
    export type RestatementSignal = 'you_opener' | 'asking_frame' | 'verbatim_run';
    export interface RestatementResult {
      restates: boolean;
      signals: RestatementSignal[];
      longestRun: number;      // longest contiguous run of normalized words shared with the query
      overlap: number;         // informational only: share of summary content words found in the query, 0..1, 2 decimals
      contentTokens: number;
    }
    export function detectHeroRestatement(query: string, summary: string | null | undefined): RestatementResult;
    export function heroRestatementGuardEnabled(): boolean; // process.env.HERO_RESTATEMENT_GUARD_ENABLED !== 'false'
    ```
    Rules:
    - Normalize both strings: lowercase, map ’‘ to ', “” to ", split on /[^a-z0-9']+/, drop empty tokens.
    - you_opener: summary matches `/^\s*["'“‘]?you(?:['’](?:re|ve|d|ll)\b|\s+(?:are|have|want|need|would|should|might|can)\b)/i`.
    - asking_frame (anywhere): `/\byou(?:['’]re|\s+are)\s+(?:asking|looking|trying|wondering|hoping|after|weighing|deciding)\b|\byou\s+(?:want|need|would like)\b|\byou['’]d\s+like\b|\byour\s+question\b/i`.
    - verbatim_run: longest common contiguous token run between normalized query and summary (all words, stopwords included; O(n*m) DP is fine) >= HERO_RESTATEMENT_CONFIG.verbatimRun.
    - overlap: content tokens = normalized tokens of length >= 3 not in a small stopword set (the, and, for, with, that, this, our, your, you, are, was, were, have, has, from, about, into, what, how, can, would, should, they, their, them, its) with a trailing "s" removed; overlap = |summary content in query content| / |summary content| (0 when none). Not used in `restates`.
    - restates = signals.length > 0. Signal order in the array: you_opener, asking_frame, verbatim_run.
    Write the tests in eval/hero-restatement.test.ts first (RED), then implement (GREEN). Add a test that `HERO_RESTATEMENT_GUARD_ENABLED=false` makes heroRestatementGuardEnabled() false and unset makes it true (restore the env var after).

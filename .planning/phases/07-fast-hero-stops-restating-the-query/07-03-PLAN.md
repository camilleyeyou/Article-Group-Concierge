<objective>
Add a deterministic fallback: when a hero challengeSummary still restates the query (whatever the prompt does), drop the restating sentences, behind kill switches, on both routes; then replay it free over every saved answer and review the changes.

Purpose: HERO-03. Prompt-only fixes backfired in Phase 6 (06-05/06-07). A removal-only guard cannot add an unsupported claim (Core Value) and caps the restatement rate even if v2 underperforms. HeroBlock renders without challengeSummary (src/components/HeroBlock.tsx renders it conditionally), so removing the field is safe. Known UX cost: on the stream route the fast hero's summary streams live and is removed when `final` arrives (same residual-risk class as 06.1's unguarded deltas); with v2 the guard should fire rarely, and the trial measures how often.
Output: guard rule + wiring + tests, free replay report with review.
</objective>

<objective>
Build a free tool that traces each unsupported claim the grader flagged in the saved runs to the text that produced it, run it on every harness-v4 run, and write the trace report.

Purpose: The phase goal is to find where the remaining unsupported claims come from (hero pass, teaser summaries or narrative) before changing anything, so fixes are targeted. Planning-time evidence already shows a measurement gap that this report must quantify: in all 50 records of 2026-11-25T14-30-56 the user saw the fast hero-pass HeroBlock, but `raw_response` (what the grader reads, eval/rubric.ts line ~153) still contains the main call's HeroBlock, because orchestrateStream substitutes the fast hero into `layoutPlan` after `rawResponse` was rendered. So hero-pass text the user saw was never graded, and graded hero text was never shown.
Output: eval/trace-claims.ts (+ test), 06.1-TRACE.json, 06.1-TRACE.md, 06.1-TRACE-OVERRIDES.json.
</objective>
